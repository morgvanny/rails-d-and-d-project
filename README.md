# Rails D&D Character Manager

A Ruby on Rails application for organizing Dungeons & Dragons characters and
parties.

## Description

This web application allows users to create, manage, and organize their D&D
characters and parties. Users can create multiple characters, join or create
parties, and keep track of character stats and information.

## Features

- User authentication (sign up, log in, log out)
- Create and manage D&D characters
- Create and join parties
- Character stat tracking (strength, dexterity, constitution, etc.)
- Character secrets management
- View all characters across the application

## Installation

1. Clone the repository:

   ```
   git clone https://github.com/your-username/rails-d-and-d-project.git
   cd rails-d-and-d-project
   ```

2. Install dependencies:

   ```
   bundle install
   ```

3. Set up the database:

   ```
   rails db:create
   rails db:migrate
   ```

4. Start the Rails server:

   ```
   rails server
   ```

5. Visit `http://localhost:3000` in your web browser to use the application.

## Usage

1. Sign up for an account or log in if you already have one.
2. Create a new character by clicking on "Create a Character" and filling out
   the form.
3. Join an existing party or create a new one.
4. View and edit your characters' details, including stats and secrets.
5. Check the character list to see all characters in the application.
